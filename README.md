This is a chatbot that runs without internet!
Here, Phi-3 mini - open weight model, from microsoft, is used, very light weight - works well even on 4gb ram!

1. install ollama from ollama.com
2. run: ollama run phi3:mini in terminal
3. install python module
4. then run main.py
that's it!

how it works?:
your question -> python -> local model -> answer.

No API, no internet after intialization.
