This is a chatbot that runs without internet! Phi-3 Mini - open-weight model from Microsoft, very lightweight - works well even on 4GB RAM.

Install Ollama from http://ollama.com
Run: `ollama run phi3:mini` in terminal
Install Python module: `pip install ollama`
Then run `main.py` — that's it!

How it works?: Your question -> Python -> Local model -> Answer
